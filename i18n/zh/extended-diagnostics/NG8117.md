# 在文本插值中应该调用函数

此诊断（Diagnostic）用于检测文本插值（Interpolation）中未被调用的函数。

```ts
import {Component} from '@angular/core';

@Component({
  template: `{{ getValue }}`,
})
class MyComponent {
  getValue() {
    return 'value';
  }
}
```

## 这有什么问题？

文本插值中的函数应该被调用以返回一个值。
如果没有调用该函数，它就不会返回任何值，插值也无法按预期工作。

## 应该怎么做？

在文本插值中使用函数时，请务必调用它，以便返回值。

```ts
import {Component} from '@angular/core';

@Component({
  template: `{{ getValue() }}`,
})
class MyComponent {
  getValue() {
    return 'value';
  }
}
```

## 配置要求

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`uninvokedFunctionInTextInterpolation` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "uninvokedFunctionInTextInterpolation": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
