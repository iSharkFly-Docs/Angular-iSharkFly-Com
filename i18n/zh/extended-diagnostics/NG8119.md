# 数值型 CSS 属性需要单位

此诊断（Diagnostic）用于检测将数值绑定到需要 CSS 单位才能生效的 CSS 长度属性的情况。

```html
<!-- 绑定一个纯数字——不会产生任何视觉效果 -->
<div [style.width]="500"></div>

<!-- 绑定一个数字字符串——同样没有效果 -->
<div [style.padding]="'20'"></div>
```

## 这有什么问题？

`width`、`height`、`margin`、`padding`、`font-size` 等许多 CSS 长度属性都需要单位（例如 `px`、`em`、`%`、`rem`）才能生效。绑定像 `500` 这样的纯数字，会把该属性设置为字符串 `"500"`，浏览器会把它当作无效值并静默忽略。元素渲染出来的效果就好像从未应用过这个样式一样。

## 应该怎么做？

在 Angular 模板（Template）中，有两种惯用方式来绑定带单位的长度值。

### 使用单位后缀简写

使用 `.unit` 后缀语法，把所需的单位直接追加到绑定名称后面：

```html
<div [style.width.px]="500"></div>
<div [style.padding.rem]="1.5"></div>
<div [style.margin-top.%]="10"></div>
```

### 绑定一个已包含单位的字符串

如果需要动态拼接值，可以改为绑定一个完整的 CSS 值字符串：

```html
<div [style.width]="'500px'"></div>
<div [style.padding]="myPadding + 'px'"></div>
```

## 配置要求

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）
才会输出。
`numericCssPropertyRequiresUnit` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "numericCssPropertyRequiresUnit": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
