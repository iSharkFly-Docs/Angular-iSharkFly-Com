# 在模板插值中必须调用信号

此诊断（Diagnostic）用于检测模板插值（Interpolation）中未被调用的信号（Signal）。

```ts
import {Component, signal, Signal} from '@angular/core';

@Component({
  template: `<div>{{ mySignal }}</div>`,
})
class MyComponent {
  mySignal: Signal<number> = signal(0);
}
```

## 这有什么问题？

Angular 信号是无参函数（`() => T`）。执行时，它们会返回信号的当前值。
这意味着在模板插值中使用信号来渲染其值时，应该调用它们。

## 应该怎么做？

在模板插值中使用信号来渲染其值时，请务必调用该信号。

```ts
import {Component, signal, Signal} from '@angular/core';

@Component({
  template: `<div>{{ mySignal() }}</div>`,
})
class MyComponent {
  mySignal: Signal<number> = signal(0);
}
```

## 配置要求

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`interpolatedSignalNotInvoked` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "interpolatedSignalNotInvoked": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
