# 未使用的独立导入

此诊断（Diagnostic）用于检测 `@Component` 的 `imports` 数组中包含了
未在模板（Template）中使用的符号的情况。

```ts
@Component({
  imports: [UsedDirective, UnusedPipe],
})
class AwesomeCheckbox {}
```

## 这有什么问题？

未使用的导入会给代码增加不必要的干扰，还可能延长编译时间。

## 应该怎么做？

删除未使用的导入。

```ts
@Component({
  imports: [UsedDirective],
})
class AwesomeCheckbox {}
```

## 如果无法避免怎么办？

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "unusedStandaloneImports": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断（Extended Diagnostics）配置](/extended-diagnostics#configuration)。
