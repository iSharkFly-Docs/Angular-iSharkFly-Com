# 未加括号的空值合并

此诊断（Diagnostic）用于检测空值合并（nullish coalescing）运算符（`??`）与逻辑或（`||`）或逻辑与（`&&`）运算符
混用、却没有用括号来明确优先级的情况。

<!-- prettier-ignore -->
```ts
import {Component, input} from '@angular/core';

@Component({
  template: `<button [disabled]="hasPermission() && task()?.disabled ?? true">Run</button>`,
})
class MyComponent {
  hasPermission = input(false);
  task = input<Task | undefined>(undefined);
}
```

## 这有什么问题？

如果没有用括号来消除歧义，就很难看出是先对 `??` 还是先对 `||`/`&&` 求值。
在 TypeScript 和 JavaScript 中这被视为错误，但在 Angular 模板中一直以来都是允许的。

## 应该怎么做？

在这类情况下，始终使用括号来消除歧义。如果你不确定代码原本的意图，
但又想保持行为不变，就把括号加在 `??` 运算符两侧。

```ts
import {Component, input} from '@angular/core';

@Component({
  template: `<button [disabled]="hasPermission() && (task()?.disabled ?? true)">Run</button>`,
})
class MyComponent {
  hasPermission = input(false);
  task = input<Task | undefined>(undefined);
}
```
