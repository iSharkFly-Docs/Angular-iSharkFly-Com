# 什么是 Angular？

Angular 是一个 Web 框架，它帮助<br/>
开发者构建快速、可靠、深受用户喜爱的应用。


<div style="margin: 2em">
  Angular 由 Google 的专职团队维护，提供了丰富的工具、API 和库，
  帮助你简化并优化开发流程。Angular 为你提供了一个坚实的平台，
  用来构建快速、可靠的应用，并能随着团队规模和代码库规模的增长而扩展。
  Angular.dev 是 Angular 文档的官方站点。
</div>

- [**教程**](/tutorials)：在浏览器中按步骤学习


**助力开发的特性**

- [**组件**](/essentials/components)：Angular 组件（Component）让你可以轻松地把代码拆分为封装良好的部分。
- [**Angular 信号**](/essentials/signals)：我们的细粒度响应式模型与编译期优化相结合，既简化了开发，又让应用默认就更快。
- [**服务端渲染**](/guide/ssr)：Angular 同时支持服务端渲染（SSR）和静态站点生成（SSG），并支持完整的 DOM 水合（Hydration）。
- [**依赖注入**](/essentials/dependency-injection)：在整个应用的各个组件之间轻松共享代码。
- [**Angular 路由**](/guide/routing)：提供功能丰富的导航工具集，支持路由守卫、数据解析、延迟加载（Lazy Loading）等众多功能。
- [**Angular 中的表单**](/guide/forms)：为表单参与和校验提供一套标准化的体系。


**以前所未有的速度开发应用**

- [**CLI**](/tools/cli)：Angular CLI 能在一分钟内让你的项目运行起来，并提供将其发展为已部署生产应用所需的各种命令。
- [**DevTools**](/tools/devtools)：Angular DevTools 与浏览器开发者工具并列使用。它可以帮助你调试和分析应用，提供组件树检查器、依赖注入（Dependency Injection）树视图以及自定义性能分析火焰图。
- [**ng update**](/update)：Angular CLI 的 `ng update` 会执行自动化代码转换，自动处理常规的破坏性变更，大幅简化主版本升级。紧跟最新版本能让你的应用尽可能快速、安全。
- [**语言服务**](/tools/language-service)：Angular 的 IDE 语言服务为你喜爱的编辑器提供代码补全、导航、重构和实时诊断功能。


**放心发布**

- [**每次提交都在 Google 庞大的单体仓库中验证**](https://cacm.acm.org/research/why-google-stores-billions-of-lines-of-code-in-a-single-repository/)：<p>Angular 的每一次提交都会在 Google 内部代码仓库中经过数十万个测试的检验，覆盖无数真实场景。</p> <p>Angular 致力于为 Google 一些最大的产品（包括 Google Cloud）提供稳定性。这一承诺确保所有变更都经过充分测试、向后兼容，并尽可能提供迁移工具。</p>
- [**清晰的支持策略和可预测的发布计划**](/reference/releases)：Angular 可预测的、基于时间的发布计划，让你的组织对框架的稳定性和向后兼容性充满信心。长期支持（LTS）窗口确保你在需要时获得关键的安全修复。官方的升级工具、指南和自动化迁移 schematics 帮助你的应用紧跟框架和 Web 平台的最新进展。


**适用于任何规模**

- [**借助国际化支持触达世界各地的用户**](/guide/i18n)：Angular 的国际化特性负责处理消息翻译和格式化，并支持 Unicode 标准的 ICU 语法。
- [**默认安全，保护你的用户**](/best-practices/security)：Angular 与 Google 世界一流的安全工程师合作，力求让开发默认就是安全的。内置的安全特性（包括 HTML 净化和可信类型支持）帮助你的用户免受跨站脚本和跨站请求伪造等常见漏洞的侵害。
- [**借助 Vite 和 esbuild 让大型团队保持高效**](/tools/cli/build-system-migration)：Angular CLI 内置了基于 Vite 和 esbuild 的快速、现代的构建流水线。有开发者反馈，构建数十万行代码的项目只需不到一分钟。
- **已在 Google 一些最大的 Web 应用中得到验证**：从 [Google Fonts](https://fonts.google.com/) 到 [Google Cloud](https://console.cloud.google.com)，Google 的大型产品都构建在 Angular 的架构之上，并帮助开发新特性，进一步提升 Angular 的可扩展性。


**开源优先**

- [**在 GitHub 上公开开发**](https://github.com/angular/angular)：想知道我们正在做什么吗？每一个 PR 和提交都可以在我们的 GitHub 上看到。遇到问题或 bug 了吗？我们会定期分类处理 GitHub issue，确保及时响应、积极参与社区，并解决你所面临的实际问题。
- [**以透明的方式构建**](/roadmap)：我们的团队会公开发布当前和未来工作的路线图，并重视你的反馈。对于较大的功能变更，我们会发布征求意见稿（RFC）来收集反馈，确保在塑造 Angular 未来方向时能听到社区的声音。


**蓬勃发展的社区**

- [**课程、博客和资源**](https://devlibrary.withgoogle.com/products/angular?sort=added)：我们的社区由才华横溢的开发者、作者、讲师、播客主播等组成。Google for Developers 资料库只是众多高质量资源中的一小部分，供新手和经验丰富的开发者持续学习。
- [**开源**](https://github.com/angular/angular/blob/main/CONTRIBUTING.md)：我们感谢那些让 Angular 成为人人受益的更好框架的开源贡献者。从修正文档中的一个错别字，到添加重要特性，我们欢迎任何感兴趣的人从我们的 GitHub 开始参与。
- [**社区合作**](https://developers.google.com/community/experts/directory?specialization=angular)：我们的团队与个人、教育者和企业合作，确保持续为开发者提供支持。Angular Google 开发者专家（GDE）是世界各地的社区领袖，他们使用 Angular 进行教学、组织活动和开发。企业合作则帮助确保 Angular 能很好地满足技术行业领导者的规模需求。
- **与其他 Google 技术合作**：<p>Angular 与 Google 的其他技术和团队紧密合作，共同改进 Web。</p> <p>我们与 Chrome Aurora 团队的持续合作，积极探索如何改善整个 Web 的用户体验，开发了 <code>NgOptimizedImage</code> 等内置性能优化，并改进了 Angular 的 Core Web Vitals 表现。</p> <p>我们还与 <a href="https://firebase.google.com/" target="_blank">Firebase</a>、<a href="https://www.tensorflow.org/" target="_blank">TensorFlow</a>、<a href="https://flutter.dev/" target="_blank">Flutter</a>、<a href="https://m3.material.io/" target="_blank">Material Design</a> 和 <a href="https://cloud.google.com/" target="_blank">Google Cloud</a> 合作，确保在整个开发工作流中提供有意义的集成。</p>
