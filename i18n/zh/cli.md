# CLI 参考

| 命令                            | 别名      | 描述                                                                                               |
| :--------------------------------- | :--------- | :-------------------------------------------------------------------------------------------------------- |
| [`add`](https://angular.dev/cli/add)                   |            | 为你的项目添加对外部库的支持。                                                     |
| [`analytics`](https://angular.dev/cli/analytics)       |            | 配置 Angular CLI 使用情况指标的收集。                                                    |
| [`build`](https://angular.dev/cli/build)               | `b`        | 将 Angular 应用或库编译到指定输出路径下名为 dist/ 的输出目录中。 |
| [`cache`](https://angular.dev/cli/cache)               |            | 配置持久化磁盘缓存并获取缓存统计信息。                                            |
| [`completion`](https://angular.dev/cli/completion)     |            | 为你的终端设置 Angular CLI 自动补全。                                                      |
| [`config`](https://angular.dev/cli/config)             |            | 获取或设置工作区 angular.json 文件中的 Angular 配置值。                |
| [`deploy`](https://angular.dev/cli/deploy)             |            | 为指定项目或工作区中的默认项目调用部署构建器。           |
| [`e2e`](https://angular.dev/cli/e2e)                   | `e`        | 构建并启动 Angular 应用，然后运行端到端测试。                                     |
| [`extract-i18n`](https://angular.dev/cli/extract-i18n) |            | 从源代码中提取 i18n 消息。                                                                  |
| [`generate`](https://angular.dev/cli/generate)         | `g`        | 基于原理图（schematic）生成和/或修改文件。                                                     |
| [`lint`](https://angular.dev/cli/lint)                 |            | 在指定项目文件夹中对 Angular 应用代码运行代码检查工具。                                 |
| [`new`](https://angular.dev/cli/new)                   | `n`        | 创建一个新的 Angular 工作区。                                                                          |
| [`run`](https://angular.dev/cli/run)                   |            | 运行一个 Architect 目标，可选择使用项目中定义的自定义构建器配置。           |
| [`serve`](https://angular.dev/cli/serve)               | `s`, `dev` | 构建并启动你的应用，并在文件更改时重新构建。                                           |
| [`test`](https://angular.dev/cli/test)                 | `t`        | 运行项目中的单元测试。                                                                             |
| [`update`](https://angular.dev/cli/update)             |            | 更新你的工作区及其依赖。参阅[更新指南](https://angular.dev/update-guide)。                       |
| [`version`](https://angular.dev/cli/version)           | `v`        | 输出 Angular CLI 版本。                                                                              |
