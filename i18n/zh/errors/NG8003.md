# 缺少引用目标

<iframe src="https://www.youtube.com/embed/fUSAg4kp2WQ" title="Video" style="width:100%;aspect-ratio:16/9;border:0" allowfullscreen></iframe>

Angular 找不到导出名为 `{{ PLACEHOLDER }}` 的指令。
这通常是因为缺少导入，或者指令上缺少 [`exportAs`](https://angular.dev/api/core/Directive#exportAs)。

::: tip 提示
这是一个常见运行时错误 [NG0301：未找到导出](/errors/NG0301) 在编译器中的对应版本。

:::

## 调试该错误

使用未找到的导出的字符串名称，追踪使用了该导出的模板或模块。

确保所有依赖都已在模块中正确导入和声明。
例如，如果未找到的导出是 `ngForm`，就需要导入 `FormsModule`，并在 `*.module.ts` 的 imports 列表中声明它，以解决缺少导出的错误。

```ts

import { FormsModule } from '@angular/forms';

@NgModule({
…
imports: [
FormsModule,
…

```

如果你最近添加了导入，需要重启服务器才能看到这些更改。
