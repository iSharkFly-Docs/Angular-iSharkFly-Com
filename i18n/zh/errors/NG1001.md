# 参数不是字面量

为了加快 Angular 编译器中元数据的提取速度，装饰器 `@NgModule`、`@Pipe`、`@Component`、`@Directive` 和 `@Injectable` 只接受对象字面量作为参数。

这是 [Ivy 中的一项有意为之的变更](https://github.com/angular/angular/issues/30840#issuecomment-498869540)，它对装饰器参数的要求比 View Engine 更加严格。
Ivy 之所以需要这种方式，是因为它在编译装饰器时会把其中的表达式移动到类输出中的其他位置。

## 调试此错误

把所有声明：

```ts
const moduleDefinition = {…}

@NgModule(moduleDefinition)
export class AppModule {
  constructor() {}
}

```

移到装饰器中：

```ts

@NgModule({…})
export class AppModule {
  constructor() {}
}

```
