# EnvironmentProviders 用在了错误的上下文中

当 `EnvironmentProviders` 被用在只接受普通提供者（Provider）的上下文中（例如组件的 `providers` 数组）时，就会发生此错误。环境提供者是为应用级配置而设计的，只能用在环境注入器（Injector）中（例如在 `bootstrapApplication` 或路由配置中配置的根注入器）。

## 常见场景

### 在组件提供者中使用 `provideHttpClient()`

`provideHttpClient()` 这样的函数返回的是 `EnvironmentProviders`，不能在组件级别使用：

```ts
@Component({
  providers: [
    provideHttpClient(), // 错误：这里不能使用 EnvironmentProviders
  ],
})
export class UserProfile {}
```

### 在组件提供者中使用 `importProvidersFrom()`

`importProvidersFrom()` 函数同样返回 `EnvironmentProviders`：

```ts
@Component({
  providers: [
    importProvidersFrom(SomeModule), // 错误：不能用于组件提供者
  ],
})
export class DataView {}
```

## 调试该错误

把环境提供者移到合适的位置：

### 应用级提供者

在 `bootstrapApplication` 中配置环境提供者：

```ts
bootstrapApplication(App, {
  providers: [provideHttpClient(), importProvidersFrom(SomeModule)],
});
```

### 路由级提供者

使用路由配置中的 `providers` 数组：

```ts
const routes: Routes = [
  {
    path: 'admin',
    component: AdminView,
    providers: [provideHttpClient(withInterceptors([authInterceptor]))],
  },
];
```

### 组件级服务

如果你需要组件作用域的服务，请使用普通提供者，而不是环境提供者：

```ts
@Component({
  providers: [
    UserClient, // 普通提供者——可以正常工作
    {provide: API_URL, useValue: '/api'}, // 值提供者——可以正常工作
  ],
})
export class UserProfile {}
```
