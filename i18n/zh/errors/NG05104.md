# 未找到根元素。

被引导的组件定义在 `@NgModule` 装饰器的 `bootstrap` 属性中；对于独立组件（Standalone Component），则作为 `bootstrapApplication` 的第一个参数传入。

当 Angular 尝试引导这些组件之一，却在 DOM 中找不到其对应的节点时，就会发生此错误。

## 调试此错误

当选择器与标签不匹配时会出现这个问题

```ts
@Component({
  selector: 'my-app',
  ...
})
export class App {}
```

<!-- prettier-ignore -->
```html
<html>
  <app-root></app-root> <!-- 与选择器不匹配 -->
</html>
```

把标签替换为正确的标签：

<!-- prettier-ignore -->
```html
<html>
  <my-app></my-app> <!-- 正确 -->
</html>
```
