# 引导的 NgModule 未指定要初始化的组件

此错误表示用于引导应用的 NgModule 缺少关键信息，导致 Angular 无法继续执行引导过程。

当 `@NgModule` 注解中缺少 NgModule 的 `bootstrap` 属性（或其值为空数组），并且该 NgModule 类上也没有定义 `ngDoBootstrap` 生命周期钩子（Lifecycle Hook）时，就会发生此错误。

有关引导过程的更多信息，请参阅[这篇指南](/guide/ngmodules/overview)。

下面的示例会触发此错误。

```ts
@NgModule({
  declarations: [App],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
})
export class AppModule {}

// `AppModule` 被用于引导，但缺少 `@NgModule.bootstrap` 字段。
platformBrowser().bootstrapModule(AppModule);
```

```ts
@NgModule({
  declarations: [App],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
  bootstrap: [],
})
export class AppModule {}

// `AppModule` 被用于引导，但 `@NgModule.bootstrap` 字段是一个空数组。
platformBrowser().bootstrapModule(AppModule);
```

## 调试此错误

请确保用于引导的 NgModule 配置正确：

- 要么 `@NgModule` 注解中存在 `bootstrap` 属性（并且包含一个非空数组）
- 要么 NgModule 类上存在 `ngDoBootstrap` 方法
