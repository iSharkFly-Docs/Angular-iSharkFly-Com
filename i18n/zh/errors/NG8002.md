# 无效的属性

<iframe src="https://www.youtube.com/embed/wfLkB3RsSJM" title="Video" style="width:100%;aspect-ratio:16/9;border:0" allowfullscreen></iframe>

某个 attribute 或 property 在编译期间无法被解析。

当尝试绑定到一个不存在的属性时，就会出现此错误。
任何属性绑定（Property Binding）都必须对应以下两者之一：

- HTML 元素上的原生属性，或者
- 应用在该元素上的组件或指令的 `input()`/`@Input()` 属性。

与此对应的运行时错误是 `NG0303: Can't bind to '${propName}' since it isn't a known property of '${tagName}'`。

## 调试该错误

查阅所用的具体[绑定语法](/guide/templates)的文档。这通常是拼写错误或导入不正确造成的。
也可能是缺少带有属性选择器 'name' 的指令，或者缺少输入属性。
