# `inject()` 必须在注入上下文中调用

当你试图在允许的[注入上下文](/guide/di/dependency-injection-context)之外使用 [`inject`](https://angular.dev/api/core/inject) 函数时，就会看到此错误。注入上下文在类的创建和初始化期间可用，对于和 `runInInjectionContext` 一起使用的函数也同样可用。

实际上，可以在构造函数、构造函数参数和字段初始化器中调用 `inject()`：

```ts
@Service()
export class Car {
  radio: Radio | undefined;

  // 可以：字段初始化器
  spareTyre = inject(Tyre);

  constructor() {
    // 可以：构造函数体
    this.radio = inject(Radio);
  }
}
```

在提供者（Provider）的工厂函数中调用 [`inject`](https://angular.dev/api/core/inject) 也是合法的：

```ts
providers: [
  {
    provide: Car,
    useFactory: () => {
      // 可以：类的工厂函数
      const engine = inject(Engine);
      return new Car(engine);
    },
  },
];
```

在类的创建过程或 `runInInjectionContext` 之外调用 [`inject`](https://angular.dev/api/core/inject) 函数会导致错误。最需要注意的是，在类实例创建之后、在方法（包括生命周期钩子（Lifecycle Hook））中都不允许调用 `inject()`：

```ts
@Component({ ... })
export class Car {
  ngOnInit() {
    // 错误：太晚了，组件实例已经创建好了
    const engine = inject(Engine);
    engine.start();
  }
}
```

## 调试此错误

从错误的调用栈倒推，找出不允许调用 `inject()` 的位置。

要修复此错误，请把 [`inject`](https://angular.dev/api/core/inject) 调用移到允许的位置（通常是类的构造函数或字段初始化器）。

::: info 注意
如果你在测试环境中运行，`TestBed.runInInjectionContext` 可以让 `inject()` 调用成功。

:::

```ts
TestBed.runInInjectionContext(() => {
  // ...
});
```
