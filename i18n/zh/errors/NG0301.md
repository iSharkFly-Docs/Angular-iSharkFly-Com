# 未找到导出

<iframe src="https://www.youtube.com/embed/fUSAg4kp2WQ" title="Video" style="width:100%;aspect-ratio:16/9;border:0" allowfullscreen></iframe>

Angular 找不到导出名为 `{{ PLACEHOLDER }}` 的指令。导出名是在指令装饰器的 `exportAs` 属性中指定的。在模板中使用 FormsModule 或 Material 模块却忘记导入相应模块时，经常会出现这种情况。

::: tip 提示
这是常见编译器错误 [NG8003：缺少引用目标](/errors/NG8003) 在运行时的对应错误。

:::

## 调试该错误

根据导出名追踪使用了该导出的模板或模块。

确保所有依赖都已在 NgModule 中正确导入和声明。例如，如果找不到的导出是 `ngForm`，就需要导入 `FormsModule`，并在 `*.module.ts` 的 imports 列表中声明它，才能解决这个错误。

```ts

import { FormsModule } from '@angular/forms';

@NgModule({
…
imports: [
FormsModule,
…

```

如果你最近添加了导入，可能需要重启服务器才能看到这些变更。
