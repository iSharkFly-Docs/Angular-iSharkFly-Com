# 水合时缺少文本

这个错误与[错误 NG0500](/errors/NG0500) 类似，但它表示 Angular 的水合（Hydration）过程期望在 DOM 中的某个特定位置找到一个文本节点，却什么也没找到。与直接操作 DOM 有关的原因，请查看[错误 NG0500](/errors/NG0500) 页面。

## 一个常见原因：服务端 HTML 在水合之前被修改了

水合会复用服务端渲染生成的文本节点。如果在浏览器运行应用之前，有什么东西移除或合并了这些文本节点，Angular 要找的节点就不存在了。

常见的来源包括：HTML 压缩工具、改写响应内容的代理或 CDN、浏览器扩展，或者在 Angular 之外用 `innerHTML` 写入文本的应用代码。

## 调试该错误

关于调试与直接操作 DOM 有关的原因，请参阅[错误 NG0500](/errors/NG0500) 中的提示。

比较服务器发送的 HTML 与浏览器接收到的 HTML。请查看页面源代码，而不是元素检查器，因为检查器显示的是水合已经运行之后的 DOM。如果文本出现在服务端响应中，却在浏览器中缺失，请排查位于两者之间、会改写 HTML 的工具。

如果你无法控制某个组件的 HTML，作为最后手段，可以在它的宿主节点上添加 `ngSkipHydration` 属性。这会为该组件及其子组件禁用水合，并且应当被视为一个需要修复的 bug。
