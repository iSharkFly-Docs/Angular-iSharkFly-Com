# 选择器冲突

<iframe src="https://www.youtube.com/embed/z_3Z5mOm59I" title="Video" style="width:100%;aspect-ratio:16/9;border:0" allowfullscreen></iframe>

两个或更多[组件](/guide/components)使用了相同的元素选择器。由于一个元素只能关联一个组件，选择器必须是唯一的字符串，以免 Angular 产生歧义。

当你在单个节点上应用了两个选择器，而它们各自匹配不同的组件时；或者你在节点上应用了单个选择器，而它匹配了多个组件时，就会在运行时出现此错误。

```ts
import {Component} from '@angular/core';

@Component({
  selector: '[stroked-button]',
  templateUrl: './stroked-button.html',
})
export class StrokedBtn {}

@Component({
  selector: '[raised-button]',
  templateUrl: './raised-button.html',
})
export class RaisedBtn {}

@Component({
  selector: 'app-root',
  template: `
    <!-- 这个节点有 2 个选择器：stroked-button 和 raised-button，它们分别匹配不同的组件：StrokedBtnComponent 和 RaisedBtnComponent，因此会抛出 NG0300  -->

    <button stroked-button raised-button></button>
  `,
})
export class App {}
```

## 调试该错误

使用错误消息中的元素名称，在代码库中搜索使用了相同选择器声明的地方：

```ts

@Component({
  selector: 'YOUR_STRING',
…
})

```

确保每个组件都有唯一的 CSS 选择器。这样可以保证 Angular 渲染的是你期望的组件。

如果你找不到使用此选择器标签名的多个组件，请检查来自导入的组件库（例如 Angular Material）中的组件。确保你遵循了选择器的[最佳实践](/style-guide#choosing-component-selectors)，以防止冲突。
