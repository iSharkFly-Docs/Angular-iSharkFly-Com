# 多个组件匹配同一个元素

编译作用域中有两个或更多[组件](/guide/components)匹配了模板中的同一个元素。
由于 Angular 只能把一个组件与给定元素关联，选择器必须足够唯一，以避免产生歧义。

::: info 注意
这是运行时错误 [NG0300：选择器冲突](/errors/NG0300) 在构建期的对应版本。在编译期检测到它意味着错误会立即暴露出来。

:::

```ts
import {Component} from '@angular/core';

@Component({
  selector: '[stroked-button]',
  template: '',
})
export class StrokedBtn {}

@Component({
  selector: '[raised-button]',
  template: '',
})
export class RaisedBtn {}

@Component({
  selector: 'app-root',
  // NG8023：StrokedBtn 和 RaisedBtn 都匹配这个元素。
  template: `<button stroked-button raised-button></button>`,
  imports: [StrokedBtn, RaisedBtn],
})
export class App {}
```

## 调试该错误

使用错误消息中的元素名称，在代码库中搜索使用了相同选择器声明的地方：

```ts

@Component({
  selector: 'YOUR_STRING',
…
})

```

确保每个组件都有唯一的 CSS 选择器。这样可以保证 Angular 渲染的是你期望的组件。

如果你找不到使用此选择器标签名的多个组件，请检查来自导入的组件库（例如 Angular Material）中的组件。确保你遵循了选择器的[最佳实践](/style-guide#choosing-component-selectors)，以防止冲突。
