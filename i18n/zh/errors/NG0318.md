# 无效的样式属性绑定值

Angular 在样式属性绑定中检测到了类型不受支持的值。这可能出现在
`[style.width]` 这样的单个绑定中，也可能出现在 `[style]` 映射的某个属性中。

样式属性值接受字符串、数字、样式 `SafeValue` 对象、`null` 和 `undefined`。
其他值，包括为非样式安全上下文创建的 `SafeValue` 对象，都会在开发模式下
产生这个警告。

例如，下面的绑定传入的是布尔值，而不是 CSS 值：

```html
<div [style.display]="isVisible"></div>
```

## 调试该错误

根据错误消息中的属性名和值找到对应的绑定。把该值转换为
有效的 CSS 字符串或数字，或者使用 `null` 或 `undefined` 来移除该样式。

当使用 `[style.width.px]` 这类单位后缀时，只绑定值的数字部分：

```html
<div [style.width.px]="width"></div>
```

不要把为其他安全上下文创建的 `SafeValue`（例如受信任的 HTML）传给样式
属性绑定。
