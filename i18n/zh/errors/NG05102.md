# 不受支持的事件目标

Angular 只把三个字符串值识别为全局事件目标：`'window'`、`'document'` 和 `'body'`。如果在注册全局事件监听器时把其他任何字符串作为目标传入，Angular 将无法解析它，并抛出此错误。

## 调试该错误

检查 `@HostListener` 或 `Renderer2.listen()` 中使用的目标名称是否有拼写错误。哪怕只是把 `'window'` 写成 `'windw'` 这样的小错误，也足以触发此错误：

```ts
@Component({
  selector: 'app-example',
  template: '<button>Click me</button>',
})
export class Example {
  @HostListener('windw:resize') // 拼写错误——应为 'window'
  onResize() {}
}
```

直接调用 `Renderer2.listen()` 并传入 Angular 不认识的字符串时，情况也一样：

```ts
this.renderer.listen('global', 'click', handler); // 不支持 'global'
```

## 修复该错误

把目标改为这三个受支持的字符串之一，或者传入一个实际的 DOM 元素而不是字符串：

```ts
@Component({
  selector: 'app-example',
  template: '<button>Click me</button>',
})
export class Example {
  @HostListener('window:resize')
  onResize() {}
}
```

```ts
// 当你需要指定更具体的目标时，使用元素引用
this.renderer.listen(this.elementRef.nativeElement, 'click', handler);
```
