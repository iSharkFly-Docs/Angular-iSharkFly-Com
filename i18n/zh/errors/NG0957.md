# @for 中使用的集合不可迭代

`@for` 循环会遍历一个数组，或者一个实现了[可迭代协议](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Iteration_protocols)的值，例如 `Map`、`Set` 或生成器。此错误表示该集合两者都不是，最常见的是一个普通对象：

```ts
@Component({
  template: `@for (item of items; track item) {
    {{ item }}
  }`,
})
class Test {
  items = {first: 'a', second: 'b'};
}
```

`null` 和 `undefined` 不会抛出错误，而是什么都不渲染，因此此错误只会报告那些存在但无法迭代的值。

## 修复该错误

要遍历普通对象的条目，请使用 [KeyValue 管道](https://angular.dev/api/common/KeyValuePipe)：

```ts
@Component({
  imports: [KeyValuePipe],
  template: `@for (item of items | keyvalue; track item.key) {
    {{ item.key }}: {{ item.value }}
  }`,
})
class Test {
  items = {first: 'a', second: 'b'};
}
```

如果该集合来自 API 调用或其他动态来源，请检查该值本身是否就是列表。响应把列表包裹在另一个对象中（例如 `{data: [...]}`）是一个常见原因。
