# 宿主指令绑定冲突

两个或多个宿主指令声明**以不同的别名暴露了同一个输入或输出**，
导致 Angular 无法合并重复的宿主指令实例。

这个错误源于[菱形组合模式](/guide/directives/directive-composition-api#host-directive-de-duplication)：
两个指令都在各自的 `hostDirectives` 中声明了同一个共享指令，但各自以不同的别名
暴露了它的某个绑定。

```ts
@Directive()
export class Shared {
  readonly value = input('');
}

@Directive({
  selector: '[dirA]',
  hostDirectives: [{directive: Shared, inputs: ['value: aliasA']}],
})
export class DirA {}

@Directive({
  selector: '[dirB]',
  hostDirectives: [{directive: Shared, inputs: ['value: aliasB']}], // 别名不同！
})
export class DirB {}

@Component({
  selector: 'app-root',
  // NG8024：Shared.value 同时被暴露为 "aliasA"（通过 DirA）和 "aliasB"（通过 DirB）。
  template: `<div dirA dirB></div>`,
  imports: [DirA, DirB],
})
export class AppComponent {}
```

## 调试该错误

错误消息会指出发生冲突的指令以及对应的输入或输出。找到所有
包含该共享指令的 `hostDirectives` 声明，检查其 `inputs` 或
`outputs` 数组中发生冲突的绑定。

要解决这个错误，可以选择以下任一方法：

- **在两处使用相同的别名。** 两个宿主指令声明必须以相同的公开名称
  暴露该绑定。
- **从其中一个或两个声明中移除别名。** 如果两个声明都不需要向使用方暴露该
  绑定，就把它从 `inputs` 或 `outputs` 数组中完全去掉。

关于 Angular 如何合并重复的宿主指令以及什么情况会构成冲突，
请参阅[宿主指令去重](/guide/directives/directive-composition-api#host-directive-de-duplication)。
