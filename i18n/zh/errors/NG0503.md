# 水合不支持 DOM 节点的内容投影

这个错误表示：在服务端序列化过程中，Angular 遇到了在 Angular 上下文之外（即使用原生 DOM API）创建的节点，并发现这些节点被作为可投影节点传入。它们很可能是通过 `ViewContainerRef.createComponent` 或 `createComponent` API 传入的。Angular 水合（Hydration）不支持这种用法。

关于水合的更多信息，请参阅[这篇指南](/guide/hydration)。

下面的示例会触发该错误。

```ts
@Component({
  selector: 'dynamic',
  template: `<ng-content />`,
})
class CardWrapper {}

@Component({
  selector: 'app',
  template: `<div #target></div>`,
})
class DynamicCard {
  @ViewChild('target', {read: ViewContainerRef}) vcr!: ViewContainerRef;
  envInjector = inject(EnvironmentInjector);

  ngAfterViewInit() {
    const div = document.createElement('div');
    const p = document.createElement('p');
    // 在这个测试中，我们在 Angular 上下文之外（即不使用 Angular API）
    // 创建 DOM 节点，并尝试对它们进行内容投影。
    // 这是不受支持的模式，会抛出异常。
    const compRef = createComponent(CardWrapper, {
      environmentInjector: this.envInjector,
      projectableNodes: [[div, p]],
    });
  }
}
```

## 调试该错误

开发者控制台中的错误消息应当包含导致问题的应用 DOM 结构具体部分的信息。检查应用的这一部分是否存在与水合相关的错误，例如使用原生 API 直接操作 DOM。

作为一种变通办法，你可以在组件的宿主节点上添加 `ngSkipHydration` 属性。
