# 跳过水合标志被应用到了无效的节点上

当 `ngSkipHydration` 属性被添加到不合适的 DOM 节点上时，就会出现这个错误。`ngSkipHydration` 属性只能应用于组件的宿主节点，可以直接写在模板中，也可以通过宿主绑定（Host Binding）添加。它不能应用于其他 DOM 节点，否则除了引发这个错误之外不会有任何效果。

关于水合（Hydration）的更多信息，请参阅[这篇指南](/guide/hydration)。

下面的示例会触发该错误。

## 示例 1

在这个示例中，`ngSkipHydration` 属性通过一个指令的宿主绑定被应用到了 `<div>` 上。由于该 `<div>` 并不是组件的宿主节点，Angular 会抛出错误。

```ts
@Directive({
  selector: '[dir]',
  host: {ngSkipHydration: 'true'},
})
class Dir {}

@Component({
  selector: 'app',
  imports: [Dir],
  template: ` <div dir></div> `,
})
class Simple {}
```

## 示例 2

在这个示例中，`ngSkipHydration` 作为属性通过模板被应用到了 `<div>` 上。
由于该 `<div>` 并不是组件的宿主节点，Angular 会抛出错误。

```ts
@Component({
  selector: 'app',
  template: ` <div ngSkipHydration></div> `,
})
class Simple {}
```

## 调试该错误

从所有无效的 DOM 节点上移除 `ngSkipHydration` 属性。或者，把 `ngSkipHydration` 属性移到组件的宿主节点上，可以写在模板中，也可以通过宿主绑定添加。
