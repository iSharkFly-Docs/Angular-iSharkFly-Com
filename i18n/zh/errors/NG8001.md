# 无效的元素

编译期间有一个或多个元素无法解析，原因是该元素不是 HTML 规范中定义的元素，或者不存在具有该元素选择器的组件（Component）或指令（Directive）。

::: tip 提示
这是常见运行时错误 `NG0304: '${tagName}' is not a known element: ...` 在编译器中的对应错误。

:::

## 调试此错误

根据错误中的元素名称，找到使用该元素的文件。

检查名称和选择器是否正确。

检查组件是否出现在 `imports` 字段中，以确保它已被正确导入到你的 NgModule 或独立组件（Standalone Component）中。如果该组件是在某个 NgModule 中声明的（即它不是独立组件），请检查它是否出现在 `exports` 字段中，以确保它已从该 NgModule 正确导出。

使用自定义元素或 Web Components 时，请确保把 [`CUSTOM_ELEMENTS_SCHEMA`](https://angular.dev/api/core/CUSTOM_ELEMENTS_SCHEMA) 添加到应用模块中。

如果这样仍未解决错误，请检查所导入的库中你正在使用的导出和属性最近是否有变化，然后重启服务器。
