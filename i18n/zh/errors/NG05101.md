# 未找到支持该事件的事件管理器插件

当 Angular 尝试为某个事件设置监听器，但已注册的事件管理器插件都无法识别该事件名时，就会出现这个错误。

## 调试该错误

错误消息中包含无法识别的事件名。只有当没有任何已注册的插件支持该事件时才会出现这个错误，例如在单元测试或自定义设置中，用一个不包含 `DomEventsPlugin` 的自定义插件列表创建了 `EventManager`。

如果该事件名是有意使用的，并且属于某个第三方插件（例如 Hammer.js 手势事件），请确保通过 `EVENT_MANAGER_PLUGINS` 令牌提供了该插件：

```ts
import {ApplicationConfig} from '@angular/core';
import {EVENT_MANAGER_PLUGINS} from '@angular/platform-browser';

export const appConfig: ApplicationConfig = {
  providers: [{provide: EVENT_MANAGER_PLUGINS, useClass: MyCustomPlugin, multi: true}],
};
```
