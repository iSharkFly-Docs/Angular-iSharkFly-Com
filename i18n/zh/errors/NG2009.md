# 无效的 Shadow DOM 选择器

使用 `ViewEncapsulation.ShadowDom` 的组件，其选择器不符合自定义元素标签名的要求。

一个标签名要被视为有效的自定义元素名称，必须：

- 全部小写。
- 包含连字符。
- 以字母（a-z）开头。

## 调试此错误

重命名组件的选择器，使其符合上述要求。

**修改前：**

```ts
@Component({
  selector: 'comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})

```

**修改后：**

```ts
@Component({
  selector: 'app-comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})
```
