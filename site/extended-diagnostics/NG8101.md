# 无效的「盒子里的香蕉」语法 {#invalid-banana-in-box}

此诊断（Diagnostic）用于检测[双向绑定（Two-way Binding）](/guide/templates/two-way-binding)中写反了的「盒子里的香蕉（banana-in-box）」语法。

```html
<user-viewer ([user])="loggedInUser" />
```

## 这有什么问题？ {#what-s-wrong-with-that}

按照目前的写法，`([var])` 实际上是一个名为 `[var]` 的[事件绑定](/guide/templates/event-listeners)。
作者的本意很可能是对名为 `var` 的变量进行双向绑定，但按现在的写法，这个绑定不会产生任何效果。

## 应该怎么做？ {#what-should-i-do-instead}

修正这个笔误。
顾名思义，香蕉 `(` 应该放在盒子 `[]` 的_里面_。
在本例中：

```html
<user-viewer [(user)]="loggedInUser" />
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`invalidBananaInBox` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "invalidBananaInBox": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
