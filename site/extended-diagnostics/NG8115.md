# 未调用的 track 函数 {#uninvoked-track-function}

此诊断（Diagnostic）用于检测 `@for` 块中未调用 track 函数的情况。

```ts
import {Component} from '@angular/core';

@Component({
  template: `@for (item of items; track trackByName) {}`,
})
class Items {
  protected trackByName(item) {
    return item.name;
  }
}
```

## 这有什么问题？ {#what-s-wrong-with-that}

`@for` 块需要唯一地标识可迭代对象中的各个条目，这样在条目被重新排序、新增或删除时，才能正确地执行 DOM 更新。
如果没有调用该函数，协调（reconciliation）算法就会使用函数引用而不是函数的返回值来比较条目。

## 应该怎么做？ {#what-should-i-do-instead}

在 `@for` 块中使用 track 函数时，请务必调用它，让函数执行，这样循环才能唯一地标识各个条目。

```ts
import {Component} from '@angular/core';

@Component({
  template: `@for (item of items; track trackByName(item)) {}`,
})
class Items {
  protected trackByName(item) {
    return item.name;
  }
}
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`uninvokedTrackFunction` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "uninvokedTrackFunction": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
