# `*ngFor` 表达式中缺少 `let` 关键字 {#missing-let-keyword-in-an-ngfor-expression}

当 `*ngFor` 中使用的表达式缺少 `let` 关键字时，会输出此诊断（Diagnostic）。

```ts
import {Component} from '@angular/core';

@Component({
  // `*ngFor` 表达式中缺少 `let` 关键字。
  template: `<div *ngFor="item of items">{{ item }}</div>`,
})
class MyComponent {
  items = [1, 2, 3];
}
```

## 这有什么问题？ {#what-s-wrong-with-that}

缺少 `let` 表明 `*ngFor` 字符串中存在语法错误。这也意味着 `item` 无法被正确地引入作用域，`{{ item }}` 也无法正确解析。

## 应该怎么做？ {#what-should-i-do-instead}

补上缺少的 `let` 关键字。

```ts
import {Component} from '@angular/core';

@Component({
  // 现在 `*ngFor` 表达式中有了 `let` 关键字，
  // 这种情况下不会输出任何诊断信息。
  template: `<div *ngFor="let item of items">{{ item }}</div>`,
})
class MyComponent {
  items = [1, 2, 3];
}
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`missingNgForOfLet` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "missingNgForOfLet": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
