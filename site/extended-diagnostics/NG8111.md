# 在事件绑定中应该调用函数 {#functions-should-be-invoked-in-event-bindings}

此诊断（Diagnostic）用于检测事件绑定（Event Binding）中未被调用的函数。

<!-- prettier-ignore -->
```ts
import {Component, signal, Signal} from '@angular/core';

@Component({
  template: `<button (click)="onClick">Click me</button>`,
})
class MyComponent {
  onClick() {
    console.log('clicked');
  }
}
```

## 这有什么问题？ {#what-s-wrong-with-that}

事件绑定中的函数应该在事件触发时被调用。
如果没有调用该函数，那么事件触发时它就不会执行。

## 应该怎么做？ {#what-should-i-do-instead}

在事件绑定中使用函数时，请务必调用它，这样事件触发时才会执行该函数。

```ts
import {Component} from '@angular/core';

@Component({
  template: `<button (click)="onClick()">Click me</button>`,
})
class MyComponent {
  onClick() {
    console.log('clicked');
  }
}
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`uninvokedFunctionInEventBinding` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "uninvokedFunctionInEventBinding": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
