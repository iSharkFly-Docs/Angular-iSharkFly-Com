# 缺少控制流指令 {#missing-control-flow-directive}

此诊断（Diagnostic）用于确保在模板（Template）中使用了已知控制流（control flow）指令
（如 `*ngIf`、`*ngFor`、`*ngSwitchCase` 或 `*ngSwitchDefault`）的独立组件（Standalone Component），也导入了
这些指令——可以单独导入，也可以通过导入 `CommonModule` 来导入。

```ts
import {Component} from '@angular/core';

@Component({
  // 模板中使用了 `*ngIf`，但没有导入对应的指令。
  imports: [],
  template: `<div *ngIf="visible">Hi</div>`,
})
class MyComponent {}
```

## 这有什么问题？ {#what-s-wrong-with-that}

在未导入的情况下使用控制流指令会在运行时失败，因为 Angular 会尝试绑定到 HTML 元素上的 `ngIf` 属性，而该属性并不存在。

## 应该怎么做？ {#what-should-i-do-instead}

确保导入了对应的控制流指令。

可以单独导入某个指令：

```ts
import {Component} from '@angular/core';
import {NgIf} from '@angular/common';

@Component({
  imports: [NgIf],
  template: `<div *ngIf="visible">Hi</div>`,
})
class MyComponent {}
```

也可以导入包含所有控制流指令的整个 `CommonModule`：

```ts
import {Component} from '@angular/core';
import {CommonModule} from '@angular/common';

@Component({
  imports: [CommonModule],
  template: `<div *ngIf="visible">Hi</div>`,
})
class MyComponent {}
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`missingControlFlowDirective` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "missingControlFlowDirective": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
