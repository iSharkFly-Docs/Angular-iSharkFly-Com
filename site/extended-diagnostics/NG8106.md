# 不支持的后缀 {#suffix-not-supported}

此诊断（Diagnostic）用于检测在属性（attribute）绑定中使用了 `.px`、`.%` 和 `.em` 后缀的情况。

```html
<img [attr.width.px]="5" />
```

## 这有什么问题？ {#what-s-wrong-with-that}

这些后缀只能用于样式绑定。绑定到属性时，它们没有任何意义。

## 应该怎么做？ {#what-should-i-do-instead}

不要使用只有样式绑定才支持的 `.px`、`.%` 或 `.em` 后缀，
而是把单位移到绑定所赋的值中。

```html
<img [attr.width]="'5px'" />
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`suffixNotSupported` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "suffixNotSupported": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
