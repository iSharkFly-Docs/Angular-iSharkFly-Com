# 未使用的 `@let` 声明 {#unused-let-declaration}

此诊断（Diagnostic）用于检测值从未在模板（Template）中被读取的 `@let` 声明。

```ts
import {Component} from '@angular/core';

@Component({
  template: `
    @let fullName = user.firstName + ' ' + user.lastName;
    <h1>Welcome</h1>
  `,
})
class MyComponent {
  user = {firstName: 'Ada', lastName: 'Lovelace'};
}
```

## 这有什么问题？ {#what-s-wrong-with-that}

未使用的 `@let` 通常是重构时遗留下来的，或者说明某处本来应该使用这个值。
每次模板更新时，Angular 仍然会对未使用的 `@let` 的表达式求值。例如，表达式中的函数调用仍然会执行。

## 应该怎么做？ {#what-should-i-do-instead}

要么使用这个声明，要么删除它：

```ts [use the declaration]
@Component({
  template: `
    @let fullName = user.firstName + ' ' + user.lastName;
    <h1>Welcome, {{ fullName }}</h1>
  `,
})
class MyComponent {
  user = {firstName: 'Ada', lastName: 'Lovelace'};
}
```

```ts [remove the declaration]
@Component({
  template: `<h1>Welcome</h1>`,
})
class MyComponent {}
```

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "unusedLetDeclaration": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断（Extended Diagnostics）配置](/extended-diagnostics#configuration)。
