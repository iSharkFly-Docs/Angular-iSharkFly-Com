# 文本属性未作为绑定 {#text-attribute-not-binding}

此诊断（Diagnostic）用于确保带有 Angular「特殊」绑定前缀（`attr.`、`style.` 和
`class.`）的属性被解析为绑定（Binding）。

```html
<div attr.id="my-id"></div>
```

## 这有什么问题？ {#what-s-wrong-with-that}

在这个例子中，`attr.id` 会被解析为一个普通属性，并原样出现
在最终的 HTML 中（`<div attr.id="my-id"></div>`）。这很可能不是开发者的本意。
开发者的本意很可能是设置 `id` 属性（`<div id="my-id"></div>`）。

## 应该怎么做？ {#what-should-i-do-instead}

绑定到 `attr.`、`class.` 或 `style.` 时，请确保使用 Angular 模板绑定语法（`[]`）。

```html
<div [attr.id]="'my-id'"></div>
<div [style.color]="'red'"></div>
<div [class.large]="true"></div>
```

## 配置要求 {#configuration-requirements}

必须启用 [`strictTemplates`](/tools/cli/template-typecheck#strict-mode)，扩展诊断（Extended Diagnostics）才会输出。
`textAttributeNotBinding` 除了 `strictTemplates` 之外没有其他要求。

## 如果无法避免怎么办？ {#what-if-i-can-t-avoid-this}

可以通过编辑项目的 `tsconfig.json` 文件来禁用此诊断：

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "textAttributeNotBinding": "suppress"
      }
    }
  }
}
```

更多信息，请参阅[扩展诊断配置](/extended-diagnostics#configuration)。
