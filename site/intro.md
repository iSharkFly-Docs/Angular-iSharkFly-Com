# Angular 简介

Angular 是一个用于构建现代 Web 应用的开发平台。它由 Google 维护，提供了一套完整的解决方案来开发单页应用（SPA）。

## 主要特性

- **组件化开发** - 使用组件构建可复用的 UI 模块
- **TypeScript** - 原生支持 TypeScript，提供类型安全
- **依赖注入** - 强大的依赖注入系统
- **路由** - 功能丰富的客户端路由
- **表单处理** - 支持模板驱动和响应式表单
- **HTTP 客户端** - 内置 HTTP 客户端用于 API 调用
- **测试** - 完善的测试工具和支持

## 快速开始

### 安装 Angular CLI

```bash
npm install -g @angular/cli
```

### 创建新项目

```bash
ng new my-app
cd my-app
ng serve
```

访问 `http://localhost:4200/` 即可看到你的应用。
