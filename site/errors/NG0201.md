# 未找到提供者 {#no-provider-found}

<iframe src="https://www.youtube.com/embed/lAlOryf1-WU" title="Video" style="width:100%;aspect-ratio:16/9;border:0" allowfullscreen></iframe>

当你试图注入一个服务（Service），却没有声明对应的提供者（Provider）时，就会看到此错误。提供者是一种映射，它提供一个值，你可以把这个值注入到应用中某个类的构造函数里。

更多关于提供者的内容，请阅读[依赖注入指南](/guide/di)。

## 调试此错误 {#debugging-the-error}

从错误中指出缺少提供者的那个对象开始倒推：`No provider for <token> found`。此错误通常在服务中抛出，因为这些服务需要的提供者并不存在。

要修复此错误，请确保你的服务已注册到某个 `NgModule` 的提供者列表中，或者在顶部带有 `@Service` 装饰器。

最常见的解决方案是在 `@Service` 中添加提供者

```ts
@Service()
```
