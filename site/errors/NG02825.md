# Fetch 响应体超出了配置的限制 {#fetch-response-body-exceeds-the-configured-limit}

当 `HttpClient` 在服务端渲染期间使用 fetch 后端，且为某个响应体缓冲的字节数超出了配置的 `maxResponseBodySize` 限制时，Angular 就会产生这个错误。默认情况下，Angular 会把每个缓冲的响应体限制在 1 MB 以内，以防服务器在渲染期间缓冲意料之外的大型响应。

## 修复该错误 {#fixing-the-error}

在 `provideServerRendering` 的选项中设置 `maxResponseBodySize` 来提高限制：

```ts
import {provideServerRendering, withRoutes} from '@angular/ssr';
import {ApplicationConfig} from '@angular/core';
import {serverRoutes} from './app.routes.server';

const serverConfig: ApplicationConfig = {
  providers: [
    provideServerRendering(
      {
        maxResponseBodySize: 5 * 1024 * 1024, // 5MB
      },
      withRoutes(serverRoutes),
    ),
  ],
};
```

`maxResponseBodySize` 用于配置对于每个使用 fetch 后端的服务端 `HttpClient` 请求，Angular 最多缓冲多少字节的响应体。该值以字节为单位，并且全局生效。

::: warning 重要
在应用允许的范围内，让这个限制尽可能小。提高该限制会让服务端请求缓冲更大的响应体，可能增加内存占用和拒绝服务的风险。尽量把大型下载移到服务端渲染之外进行。

:::

## 调试该错误 {#debugging-the-error}

错误消息中包含以字节为单位的已配置 `maxResponseBodySize` 限制。要找出是哪个 HTTP 请求返回了较大的响应，请查看网络日志或 SSR 服务器控制台中失败请求的 URL。

如果这个大型响应只在客户端需要、服务端渲染并不需要它，你可以为该请求单独禁用传输缓存：

```ts
httpClient.get('/api/large-data', {transferCache: false});
```
