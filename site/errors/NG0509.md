# 水合时路径上缺少节点 {#hydration-missing-node-on-path}

当 Angular 在水合（Hydration）期间找不到某个节点时，生产构建会显示此错误。Angular 会沿着服务端渲染期间保存的路径查找，但该路径上的某个节点缺失了。这意味着浏览器中的 DOM 与来自服务端的 HTML 不同。

生产构建不包含错误消息，因此你只能看到代码 `NG0509`。开发构建会把同样的问题显示为[错误 NG0502](/errors/NG0502)，其消息会告诉你宿主节点和路径。

## 常见原因 {#common-causes}

原因与[错误 NG0500](/errors/NG0500) 相同。另外还要检查来自应用外部的修改，例如 CDN 功能或浏览器扩展所做的修改。请阅读水合指南中的 [CDN 与浏览器扩展](/guide/hydration#cdns-and-browser-extensions)。

## 调试此错误 {#debugging-the-error}

- 如果在开发构建中能复现该问题，请使用开发构建。`NG0502` 消息会告诉你宿主节点和路径。
- 比较生产环境的 HTML 与本地服务器的 HTML。如果看到 `__cf_email__` 元素，或者注释节点缺失，那么原因很可能是某个 CDN 功能。
- 在没有安装任何扩展的浏览器配置文件中打开页面。如果错误消失了，说明是某个扩展在修改页面。
