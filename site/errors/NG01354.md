# 子组件中的 NgModel 无法访问父表单 {#ngmodel-in-child-component-cannot-reach-parent-form}

当 `ngModel`（或任何模板驱动表单（Template-driven Forms）控件）位于某个子组件中，而该子组件的父组件承载着一个表单指令（`NgForm` 或 `FormGroupDirective`），但该控件无法注册到这个表单时，就会发出此警告。

根本原因在于 `NgModel` 使用 `@Host()` 注入 `ControlContainer`，这会阻止注入器（Injector）跨越组件边界。父组件模板中的表单指令对子组件模板中的 `NgModel` 是不可见的。

结果，子组件的控件会悄无声息地以独立方式运行，不参与父表单的值、有效性或提交状态。

## 修复此警告 {#fixing-the-warning}

### 方案 1：使用 `viewProviders` 桥接 `ControlContainer` {#option-1-bridge-the-controlcontainer-with-viewproviders}

为子组件添加 `viewProviders`，使其把父表单重新导出到自己的视图中。请使用警告中提到的那个类：模板驱动表单（`<form>`）使用 `NgForm`，响应式表单（Reactive Forms）（`[formGroup]`）使用 `FormGroupDirective`：

```ts
// 父组件使用模板驱动表单：<form> ... <app-child> </form>
import {ControlContainer, NgForm} from '@angular/forms';
import {Component} from '@angular/core';

@Component({
  selector: 'app-child',
  template: `<input name="email" [(ngModel)]="email" />`,
  viewProviders: [{provide: ControlContainer, useExisting: NgForm}],
})
export class Child {
  email = '';
}
```

```ts
// 父组件使用响应式表单：<div [formGroup]="myGroup"> ... <app-child> </div>
import {ControlContainer, FormGroupDirective} from '@angular/forms';
import {Component} from '@angular/core';

@Component({
  selector: 'app-child',
  template: `<input name="email" [(ngModel)]="email" />`,
  viewProviders: [{provide: ControlContainer, useExisting: FormGroupDirective}],
})
export class Child {
  email = '';
}
```

这样，父表单就能正常识别并验证子组件的控件了。

### 方案 2：将控件标记为独立控件 {#option-2-mark-the-control-as-standalone}

如果子组件的控件确实应当独立于父表单，请显式地选择退出：

```html
<input name="email" [(ngModel)]="email" [ngModelOptions]="{standalone: true}" />
```

## 调试此警告 {#debugging-the-warning}

警告消息中包含错误代码 `NG01354`。使用调用栈找出是哪个 `ngModel` 触发了它。检查拥有 `<form>` 标签的组件和拥有 `ngModel` 输入框的组件是否是同一个组件；如果不是，请采用上述方案之一。
