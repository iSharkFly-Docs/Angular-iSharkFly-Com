# `formControlName` 缺少对应的控件 {#missing-control-for-formcontrolname}

模板中的某个 `formControlName` 指向了 `FormGroup` 中并不存在的控件。该指令按路径查找控件，却什么也没找到。

当模板和表单组基于同一份数据构建、却使用了不同的过滤条件时，就可能出现这种情况。某个条目在模板中被渲染了出来，但在表单组中从未为它创建控件，因此它的 `formControlName` 无从绑定。

```ts
@Component({
  template: `
    <form [formGroup]="form">
      <ng-container formGroupName="options">
        @for (id of visibleIds; track id) {
          <input [formControlName]="id" />
        }
      </ng-container>
    </form>
  `,
})
class App {
  // 模板为两个 id 都渲染了输入框……
  visibleIds = [1, 2];
  // ……但表单组中只有 id 1 对应的控件。
  form = new FormGroup({
    options: new FormGroup({
      1: new FormControl(''),
    }),
  });
}
```

## 调试此错误 {#debugging-the-error}

错误消息会列出该层级上实际存在的控件，例如：

```
Cannot find control with path: 'options -> 2'. Controls that do exist at this level: 1.
```

把它与模板中绑定的名称进行比较。然后，要么把缺少的控件添加到 `FormGroup` 中，要么不再为没有控件的条目渲染 `formControlName`。
