# 组件 ID 生成冲突 {#component-id-generation-collision}

创建组件（Component）时，Angular 会为每个组件生成一个唯一的组件 ID。这个 ID 根据 Angular 组件元数据生成，包括但不限于：选择器、宿主绑定的数量、类属性名、视图查询和内容查询。当两个组件的元数据完全相同时（通常是共用同一个选择器），就会发生 ID 生成冲突。

组件 ID 在 Angular 内部用于：

- 为 DOM 节点添加额外的标注，以实现样式封装
- 在[水合](/guide/hydration)期间，在[服务端渲染](/guide/ssr)之后恢复应用状态。

为了避免组件 ID 冲突可能引发的问题，建议按下文所述的方法加以解决。

## 组件 ID 冲突示例 {#example-of-a-component-id-collision}

```ts
@Component({
  selector: 'my-component',
  template: 'complex-template',
})
class Some {}

@Component({
  selector: 'my-component',
  template: 'empty-template',
})
class SomeMocked {}
```

定义了这两个组件就会触发 ID 生成冲突，并且在开发期间会显示一条警告。

## 调试此错误 {#debugging-the-error}

警告消息中包含 ID 发生冲突的两个组件的类名。

可以使用以下任一方案来解决这个问题：

1. 修改两个组件之一的选择器。例如，使用不产生实际效果的伪选择器（如 `:not()`）加上一个不同的标签名。

   ```ts
   @Component({
     selector: 'my-component:not(p)',
     template: 'empty-template',
   })
   class SomeMocked {}
   ```

1. 为其中一个组件添加一个额外的宿主属性。

   ```ts
   @Component({
     selector: 'my-component',
     template: 'complex-template',
     host: {'some-binding': 'some-value'},
   })
   class Some {}
   ```
