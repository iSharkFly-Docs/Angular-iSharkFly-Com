# 控制流阻止了内容投影 {#control-flow-preventing-content-projection}

控制流块中的某个元素或 `<ng-template>` 本应被投影到特定的 `<ng-content>` 插槽中，但由于该块有不止一个根节点，投影没有发生。

```ts
import {Component} from '@angular/core';

@Component({
  selector: 'app-card',
  template: `
    <ng-content select="[card-title]" />
    <ng-content />
  `,
})
class Card {}

@Component({
  imports: [Card],
  // NG8011：<h2 card-title> 没有被投影到 "[card-title]" 插槽中，因为 @if
  // 块有两个根节点（h2 和 p）。
  template: `
    <app-card>
      @if (showTitle) {
        <h2 card-title>Title</h2>
        <p>Subtitle</p>
      }
    </app-card>
  `,
})
class MyComponent {
  showTitle = true;
}
```

## 调试该错误 {#debugging-the-error}

控制流块模拟了 `*ngIf` 和 `*ngFor` 的内容投影行为，即投影它们所作用的那个元素。
只有当块中只有一个根节点时，这种机制才能生效。
当块中有多个根节点时，Angular 无法根据该元素来选择插槽，因此 `<h2 card-title>` 最终会落入 `Card` 的默认 `<ng-content />` 插槽，而不是 `[card-title]` 插槽。

文本也算作根节点，所以被投影元素旁边多出的一行文本也会导致同样的问题；如果包含该块的组件设置了 `preserveWhitespaces: true`，那么空白字符也会被算作根节点。

要解决这个错误，可以选择以下任一方法：

- **把内容包裹在一个使用 [`ngProjectAs`](/guide/components/content-projection#aliasing-content-for-projection) 的 `<ng-container>` 中**，使其匹配插槽的选择器。容器内的所有内容都会被投影到该插槽中。

  ```ts
  @Component({
    imports: [Card],
    template: `
      <app-card>
        @if (showTitle) {
          <ng-container ngProjectAs="[card-title]">
            <h2>Title</h2>
            <p>Subtitle</p>
          </ng-container>
        }
      </app-card>
    `,
  })
  class MyComponent {
    showTitle = true;
  }
  ```

- **把内容拆分到多个块中**，使每个块的根部都只有一个可投影的节点。

  ```ts
  @Component({
    imports: [Card],
    template: `
      <app-card>
        @if (showTitle) {
          <h2 card-title>Title</h2>
        }
        @if (showTitle) {
          <p>Subtitle</p>
        }
      </app-card>
    `,
  })
  class MyComponent {
    showTitle = true;
  }
  ```
