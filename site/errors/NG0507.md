# HTML 内容在 SSR 之后被修改 {#html-content-was-altered-after-server-side-rendering}

当 Angular 检测到服务端渲染（SSR）生成的内容在渲染之后被修改时，就会抛出这个错误。水合（Hydration）过程依赖于 SSR 之后内容保持原样，这也包括空白字符和注释节点。这些空白字符和注释节点必须保留在 SSR 过程生成的 HTML 中。更多信息请参阅水合指南。

## 调试该错误 {#debugging-the-error}

这通常发生在以下情况：

有些 CDN 提供商内置了一项优化功能，会移除 HTML 中的空白字符和注释节点。请检查 CDN 配置中是否有这样的选项，并将其关闭。
如果你对 SSR 生成的 HTML 进行了自定义后处理（作为构建步骤），请确保该过程不会移除空白字符和注释节点。
