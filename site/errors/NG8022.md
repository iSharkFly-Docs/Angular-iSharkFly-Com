# 表单字段上存在不受支持的绑定 {#unsupported-binding-on-a-form-field}

模板在使用了 `[formField]` 指令的元素上，绑定了（或以静态属性的形式设置了）一个已由信号表单（Signal Forms）控制的属性。
对于 `min`、`max`、`required`、`disabled` 和 `readonly` 等属性，字段状态是唯一的事实来源。在模板中指定它们会与字段的 schema 逻辑发生冲突。

错误消息会指出具体是哪个绑定，内容为 "Binding to '[min]' is not allowed..." 或 "Setting the 'required' attribute is not allowed..."。

```ts
import {Component, signal} from '@angular/core';
import {form, FormField} from '@angular/forms/signals';

@Component({
  selector: 'app-root',
  imports: [FormField],
  template: `
    <!-- NG8022：[min] 和 [max] 不能与 [formField] 一起使用。 -->
    <input type="number" [formField]="f.age" [min]="18" [max]="99" />

    <!-- NG8022：required 属性不能与 [formField] 一起使用。 -->
    <input type="text" [formField]="f.name" required />
  `,
})
export class App {
  f = form(signal({age: 20, name: ''}));
}
```

这同样适用于[自定义表单控件](/guide/forms/signals/custom-controls)：当模板绑定了由字段管理的输入属性时，例如在声明了 `max` 输入的控件上使用 `[max]`。

不能与 `[formField]` 一起使用的属性包括：

- **值：**`value`、`checked`（由底层的模型信号直接管理）
- **验证规则：**`required`、`min`、`max`、`minLength`、`maxLength`、`pattern`（以及原生 HTML 的 `minlength` 和 `maxlength`）
- **交互状态：**`disabled`、`readonly`、`hidden`
- **字段状态与元数据：**`name`、`dirty`、`touched`、`invalid`、`errors`、`pending`、`disabledReasons`（在自定义控件上，`FormField` 会自动把这些状态传给控件，因此手动绑定它们会与框架的自动连接相冲突）

原生元素上有几个例外：

- 在 `type` 为 `date`、`time`、`month`、`week` 和 `datetime-local` 的 `<input>` 元素上允许使用 `min` 和 `max`。在这些类型上，限制值是 `2026-01-01` 这样的日期或时间字符串，数值型的 `min()` 和 `max()` 规则无法表达。
- 当 `type` 是动态绑定的时，也允许使用 `min` 和 `max`，因为编译器无法判断该输入框是什么类型。
- 在 `<input type="radio">` 上允许使用 `value`，因为在这里它用于标识选项。哪个单选按钮被选中由字段值决定。

## 调试该错误 {#debugging-the-error}

从模板中移除该绑定，然后根据属性的类别进行处理：

- **值（`value`、`checked`）：**`[formField]` 会自动绑定元素，并与底层的模型信号进行双向同步。要初始化或修改值，请更新传给 `form()` 的模型信号。
- **验证规则**（`required`、`min`、`max`、`maxLength` 等）：使用相应的[验证规则](/guide/forms/signals/validation)，在 `form()` 的 schema 函数中声明它们。
- **交互状态**（`disabled`、`readonly`、`hidden`）：使用 schema 规则 `disabled()`、`readonly()` 和 `hidden()`。它们还接受一个可选的 `when` 条件，因此规则可以依赖其他字段。参见[表单逻辑](/guide/forms/signals/form-logic)。
- **字段状态与元数据**（`dirty`、`touched`、`errors` 等）：无需替代。`[formField]` 会根据字段状态应用它们，你也可以从字段中读取它们，例如 `f.age().dirty()`。

于是上面的示例变为：

```ts
import {Component, signal} from '@angular/core';
import {disabled, form, FormField, max, maxLength, min, required} from '@angular/forms/signals';

@Component({
  selector: 'app-root',
  imports: [FormField],
  template: `
    <input type="number" [formField]="f.age" />
    <input type="text" [formField]="f.name" />
  `,
})
export class App {
  f = form(signal({age: 20, name: ''}), (p) => {
    min(p.age, 18);
    max(p.age, 99);
    required(p.name);
    maxLength(p.name, 20);
    disabled(p.name, {when: ({valueOf}) => valueOf(p.age) < 18});
  });
}
```
