# track 表达式在给定集合中产生了重复的键 {#track-expression-resulted-in-duplicated-keys-for-a-given-collection}

`@for` 循环中指定的 track 表达式在给定集合中求值得到了重复的键，例如：

```ts
@Component({
  template: `@for (item of items; track item.value) {
    {{ item.value }}
  }`,
})
class Test {
  items = [
    {key: 1, value: 'a'},
    {key: 2, value: 'b'},
    {key: 3, value: 'a'},
  ];
}
```

在上面的示例中，`item.value` 跟踪表达式会得到两个重复的键 `a`（位于索引 0 和 2）。

从正确性的角度来看，重复的键会带来问题：由于 `@for` 循环无法唯一标识条目，在执行 DOM 移动或销毁时，它可能会选中 _另一个_ 条目（具有相同的键）所对应的 DOM 节点。

重复的键还会带来性能损耗：在遍历含有重复键的集合时，Angular 内部必须使用更复杂、更慢的数据结构。

## 修复此错误 {#fixing-the-error}

修改跟踪表达式，使其能唯一标识集合中的条目。在上述示例中，正确的 track 表达式应使用唯一的 `key` 属性（`item.key`）：

```ts
@Component({
  template: `@for (item of items; track item.key) {
    {{ item.value }}
  }`,
})
class Test {
  items = [
    {key: 1, value: 'a'},
    {key: 2, value: 'b'},
    {key: 3, value: 'a'},
  ];
}
```
