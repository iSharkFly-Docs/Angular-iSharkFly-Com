# 缺少值访问器 {#missing-value-accessor}

所有自定义表单控件都必须注册一个值访问器。

下面是一个提供值访问器的示例：

```ts
providers: [
  {
    provide: NG_VALUE_ACCESSOR,
    useExisting: forwardRef(() => MyInputField),
    multi: true,
  },
];
```

## 调试此错误 {#debugging-the-error}

如上所述，你的控件本应有一个值访问器，但却缺少了。不过在实际中，导致这种情况的原因有很多。下面列出了一些已知会导致此错误的问题。

1. 如果你**定义**了一个自定义表单控件，是否记得为它提供值访问器？
1. 你是否把 `ngModel` 放在了一个没有值的元素或**无效元素**上（例如 `<div [(ngModel)]="foo">`）？
1. 你是否在使用一个声明在 `NgModule` 中的自定义表单控件？如果是，请确保你**导入**了该 `NgModule`。
1. 你是否在第三方自定义表单控件上使用 `ngModel`？检查该控件是否提供了值访问器。如果没有，请在该控件的元素上使用 **`ngDefaultControl`**。
1. 你是否在**测试**一个自定义表单控件？请确保在测试床中配置了该控件。可以通过 `Testbed.configureTestingModule` 来完成。
1. 你是否在 webpack 中使用 **Nx 和模块联邦（Module Federation）**？你的 `webpack.config.js` 可能需要[额外的配置](https://github.com/angular/angular/issues/43821#issuecomment-1054845431)，以确保 forms 包是共享的。
