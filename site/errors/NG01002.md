# 缺少控件值 {#missing-control-value}

当你在 `FormGroup` 或 `FormArray` 上调用 `setValue`，但传入的值缺少某个已注册控件对应的条目时，就会发生此错误。

`setValue` 是严格的——它要求为每个控件都提供值。如果你只想更新部分控件，请改用 `patchValue`。

## 调试该错误 {#debugging-the-error}

查看错误消息中指出的是哪个控件，然后确保你的值对象中包含它。

此错误的一个常见来源是展开了一个不包含所有键的对象：

```ts
const someValue = {first: 'Nancy'}; // 缺少 'last'

form.setValue({...someValue}); // 抛出 NG01002
```

如果 `someValue` 来自 API 响应、部分状态更新，或者来自一个与表单结构不完全匹配的类型，就可能发生这种情况。在这些情况下，要么显式补全缺少的键，要么改用 `patchValue`。

### FormGroup {#formgroup}

```ts
const form = new FormGroup({
  first: new FormControl(''),
  last: new FormControl(''),
});

// 值中没有 'last'——抛出 NG01002
form.setValue({first: 'Nancy'});

// 两个控件都有值——正常工作
form.setValue({first: 'Nancy', last: 'Drew'});
```

### FormArray {#formarray}

```ts
const formArray = new FormArray([new FormControl(''), new FormControl('')]);

// 两个控件只有一个值——抛出 NG01002
formArray.setValue(['Nancy']);

// 每个控件一个值——正常工作
formArray.setValue(['Nancy', 'Drew']);
```
