# HttpTransferCache 未传递请求头 {#headers-not-transferred-by-httptransfercache}

当代码尝试访问某个没有通过 `HttpTransferCache` 从服务端传递到客户端的 HTTP 头时，Angular 会产生此警告。

默认情况下，`HttpTransferCache` 不会传递任何头，以避免潜在的安全问题或不必要的数据传输。当客户端访问了某个未被包含的头时，Angular 会记录此警告，帮助你找出缺少的头。

## 修复该错误 {#fixing-the-error}

要在传输缓存中包含特定的头，请使用 `includeHeaders` 选项。

### 在请求级别 {#at-the-request-level}

在 HTTP 请求中添加 `transferCache` 参数：

```ts
this.http.get('/api/data', {
  transferCache: {
    includeHeaders: ['cache-control', 'etag'],
  },
});
```

### 在应用级别 {#at-the-application-level}

在提供传输缓存时配置 `includeHeaders`：

```ts
provideClientHydration(
  withHttpTransferCacheOptions({
    includeHeaders: ['cache-control', 'etag'],
  }),
);
```

只包含应用逻辑确实需要的头。对敏感的头要格外谨慎。

## 调试该错误 {#debugging-the-error}

警告消息中包含头的名称和请求 URL。在代码中查找访问该头的位置，并判断是否需要把它包含在传输缓存中。

如果客户端不需要这个头，请考虑重构代码，避免访问它。
