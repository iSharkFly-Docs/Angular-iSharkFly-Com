# 启用 HMR 时 @defer 的行为 {#defer-behavior-when-hmr-is-enabled}

模块热替换（Hot Module Replacement，HMR）是开发服务器使用的一种技术，用于在只修改了应用的一部分时避免重新加载整个页面。

在 Angular 中启用 HMR 后，所有 `@defer` 块的依赖都会被立即加载，而不是等待配置的触发器（trigger）条件满足（仅客户端触发器和增量水合触发器均是如此）。这是 HMR 正常工作所必需的，以便在运行时替换应用中的组件，而无需重新加载整个页面。注意：在 HMR 模式下，defer 块的实际渲染仍然遵循触发条件。

如果你想在开发模式下测试 `@defer` 块的行为，并确保只有在满足触发条件时才加载所需的依赖，可以按照[`这篇文档`](/tools/cli/build-system-migration#hot-module-replacement)中的说明禁用 HMR 模式。
