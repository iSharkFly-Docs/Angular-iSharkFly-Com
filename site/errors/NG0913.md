# 运行时性能警告 {#runtime-performance-warnings}

### 图片尺寸过大 {#oversized-images}

图片加载时，会把下载文件的**固有尺寸**与图片在页面上的实际尺寸进行比较。实际尺寸的计算方式是：应用 CSS 后图片的**渲染尺寸**乘以[设备像素比](https://web.dev/codelab-density-descriptors/#pixel-density)。如果下载的图片大得多（任一维度超出 1200px 以上），就会触发此警告。下载尺寸过大的图片会拖慢页面加载，并对 [Core Web Vitals](https://web.dev/vitals/) 产生负面影响。

### 延迟加载的 LCP 元素 {#lazy-loaded-lcp-element}

页面加载期间最大的内容元素被称为「LCP 元素」，它与 Core Web Vitals 之一的 [Largest Contentful Paint（最大内容绘制）](https://web.dev/lcp/)相关。延迟加载 LCP 元素会对页面性能造成严重的负面影响。采用这种策略时，浏览器必须先完成布局计算，确定元素是否位于视口内，然后才开始下载图片。因此，当 Angular 检测到 LCP 元素被设置了 `loading="lazy"` 属性时，就会触发警告。

### 调试此错误 {#debugging-the-error}

使用控制台警告中提供的图片 URL 找到对应的 `<img>` 元素。

### 修复图片尺寸过大的方法 {#ways-to-fix-oversized-images}

- 使用更小的源图片
- 如果不同布局需要多种尺寸，请添加 [`srcset`](https://web.dev/learn/design/responsive-images/#responsive-images-with-srcset)。
- 改用 Angular 内置的图片指令（[`NgOptimizedImage`](https://angular.dev/api/common/NgOptimizedImage)），它会[自动生成 srcset](/guide/image-optimization#request-images-at-the-correct-size-with-automatic-srcset)。

### 修复延迟加载 LCP 元素的方法 {#ways-to-fix-lazy-loaded-lcp-element}

- 把 `loading` 属性改成其他值，例如 `"eager"`。
- 改用 Angular 内置的图片指令（[`NgOptimizedImage`](https://angular.dev/api/common/NgOptimizedImage)），它可以让你轻松地[优先加载 LCP 图片](/guide/image-optimization#mark-images-as-priority)。

### 禁用图片性能警告 {#disabling-image-performance-warnings}

可以在应用根部使用提供者（Provider），在整个站点范围内分别禁用这两种警告：

```ts
providers: [
  {
    provide: IMAGE_CONFIG,
    useValue: {
      disableImageSizeWarning: true,
      disableImageLazyLoadWarning: true
    }
  },
],
```
