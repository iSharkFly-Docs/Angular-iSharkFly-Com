# 跟踪表达式导致 DOM 结构被重新创建 {#tracking-expression-caused-re-creation-of-the-dom-structure}

`@for` 循环中指定的基于对象标识的 track 表达式导致与 _所有_ 条目对应的 DOM 都被重新创建。这是一个开销非常大的操作，在使用不可变数据结构时经常发生。例如：

```ts
@Component({
  template: `
    <button (click)="toggleAllDone()">All done!</button>
    <ul>
      @for (todo of todos; track todo) {
        <li>{{ todo.task }}</li>
      }
    </ul>
  `,
})
export class App {
  todos = [
    {id: 0, task: 'understand trackBy', done: false},
    {id: 1, task: 'use proper tracking expression', done: false},
  ];

  toggleAllDone() {
    this.todos = this.todos.map((todo) => ({...todo, done: true}));
  }
}
```

在上面的示例中，切换条目的「done」状态后，整个列表连同所有视图（DOM 节点、Angular 指令、组件、查询等）都会被重新创建（！）。而实际上，只需对 `done` 属性做一次开销相对较小的绑定更新就够了。

除了带来很高的性能损耗之外，重新创建 DOM 树还会导致 DOM 元素丢失状态（例如：焦点、文本选区、iframe 中加载的站点等）。

## 修复此错误 {#fixing-the-error}

修改跟踪表达式，使其能唯一标识集合中的条目，而不依赖于对象标识。在上述示例中，正确的 track 表达式应使用唯一的 `id` 属性（`item.id`）：

```ts
@Component({
  template: `
    <button (click)="toggleAllDone()">All done!</button>
    <ul>
      @for (todo of todos; track todo.id) {
        <li>{{ todo.task }}</li>
      }
    </ul>
  `,
})
export class App {
  todos = [
    {id: 0, task: 'understand trackBy', done: false},
    {id: 1, task: 'use proper tracking expression', done: false},
  ];

  toggleAllDone() {
    this.todos = this.todos.map((todo) => ({...todo, done: true}));
  }
}
```
